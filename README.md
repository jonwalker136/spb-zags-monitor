# SPB ZAGS Monitor

Проект для мониторинга появления свободных слотов записи в ЗАГС №1 Санкт-Петербурга.

## Возможности

- Мониторинг доступности слотов
- Уведомления в Telegram
- Настройка интервала проверки
- Логирование

## Структура

- app.py — точка входа
- config.py — настройки
- bot/ — Telegram
- monitor/ — логика мониторинга
- storage/ — хранение данных
